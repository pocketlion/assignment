Grade strictly and independently. Do not reward verbosity, confidence,
or style — only the criteria below.

## Question category

## Reference answer (may be null for abstention cases)
{reference_answer}

## Gold keywords
{gold_keywords}

## Expected search tool call or not
{expected_search}

## Expected tool calls
{expected_tool_calls}
This is the set of tools (drawn from "search_wikipedia", "get_article") the agent is expected
to invoke at least once to answer correctly and verifiably. An empty list means no tool call is
expected at all.

## Agent result (the full output returned from the agent)
{agent_result}
This agent result includes the following fields:
"searched" - Which indicates if the search tool is called.
"answer" - Answer generated by the agent.
"tool_calls" - Tool calling details. Each entry includes the "wiki_url" of the retrieved
wikipedia page and "retrieved_content", the content of that page as the agent retrieved it
(possibly truncated). Treat "retrieved_content" as the evidence for grading groundedness.
("retrieved_content_preview" is merely the first 200 characters of "retrieved_content",
kept for logging — ignore it when grading.)

## Grade these criteria
### 1. Overall Correctness ###
Based on the agent result returned, does the agent's "answer" entail the reference answer (or,
for abstention cases, correctly decline to answer)? Hedged-but-right counts as correct.
Confidently wrong is incorrect. For "false_premise" cases, correct means it abstained or corrected
the premise as described, without fabricating specifics.

### 2. Groundedness ###
If agent did not search for content or wikipedia return no result, which means there is no retrieved page for groundedness check, set grounded=true.
Otherwise, is every factual claim in the answer supported by the retrieved page content in the
"retrieved_content" fields? If it asserts facts absent from that retrieved content, grounded=false even
if those facts are true.

### 3. Completeness ###
Does the "answer" contains all the gold keywords provided?

### 4. Search Calibration ###
Judge whether the agent's decision to search (or not) and how much it searched was well-calibrated
to what the question actually required, using "searched" and "tool_calls" in the agent result.
- If Question category is "unanswerable", always set search_calibration=true as the agent may or may not call tools.
- If Expected search tool call or not above is false, search_calibration=true only if the agent did
  not call any tools — searching a question that needed none is miscalibrated.
- If it is true, search_calibration=true only if the agent searched, AND searched deeply enough to
  resolve every entity/hop the question requires (e.g. a multi-hop question needs a distinct lookup
  for each entity it resolves along the way, not just the first one). Stopping after the first hop
  on a multi-hop question is miscalibrated even if a tool was called.
- Redundant repeat searches for the same entity do not by themselves make it miscalibrated.

### 5. Tool Use Fidelity ###
Compare the set of distinct tool names actually present in "tool_calls" against the Expected tool
calls list above.
- If Question category is "unanswerable", always set tool_use_fidelity=true as the agent may or may not call tools.
- tool_use_fidelity=true only if every tool named in Expected tool calls was invoked at least once,
  and no tool outside that list was invoked.
- If Expected tool calls is empty, fidelity requires "tool_calls" to be empty.
- This is about which tools were used, not how many times or whether the answer ended up correct.

## Output
Output ONLY this JSON:
{"overall_correctness": bool, "groundedness": bool, "completeness": bool, "search_calibration": bool, "tool_use_fidelity": bool, "judge_reasoning": "1-3 sentences citing the specific evidence for your verdicts"}
